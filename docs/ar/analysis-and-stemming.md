# الاشتقاق والتحليل

تدعم دُجانة ثلاثة أوضاع رئيسية.

## Light

وضع محافظ. يزيل اللواحق والبادئات الواضحة فقط، ولا يحاول تحليلًا صرفيًا عميقًا.

## Moderate

وضع عملي أقوى من Light. يزيل بعض اللواحق والضمائر وأداة التعريف والبادئات، مع وجود حراس لمنع حذف الحروف البنيوية مثل كاف `اهتلاك` وياء `مشتهى`.

## Root

وضع صرفي يحاول الوصول إلى الجذر بالاعتماد على:

- القاموس الاختياري.
- الجذور اليدوية.
- قواعد صرفية قابلة للقياس.
- Fallback محافظ عند غياب الدليل.

لا ينبغي التعامل مع كل نتيجة في Root mode بوصفها يقينية. اقرأ المصدر والثقة وحقول الاعتمادية عند بناء نظام إنتاجي.

## مثال: أَحْلَامَهُمْ

```php
use Dujana\ArabicNlp\ArabicAnalyzer;
use Dujana\ArabicNlp\Enums\StemmerModeEnum;

$word = 'أَحْلَامَهُمْ';

$light = ArabicAnalyzer::make()->analyze($word, StemmerModeEnum::Light);
$moderate = ArabicAnalyzer::make()->analyze($word, StemmerModeEnum::Moderate);
$root = ArabicAnalyzer::make()->analyze($word, StemmerModeEnum::Root);
```

| الوضع | الغرض | السلوك المتوقع عمومًا |
|---|---|---|
| Light | اشتقاق محافظ | يحافظ على قدر أكبر من صورة الكلمة |
| Moderate | stem عملي | يزيل الضمير عندما يكون ذلك آمنًا |
| Root | تحليل صرفي | يحاول الوصول إلى الجذر عبر القاموس والقواعد |

الناتج الدقيق قد يختلف حسب الإعدادات وقاعدة القاموس وقوائم الحماية.
