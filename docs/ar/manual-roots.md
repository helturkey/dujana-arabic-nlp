# الجذور اليدوية

الجذور اليدوية ملف TSV يساعدك على تحسين النتائج في الكلمات المهمة إنتاجيًا.

للتعديل:

```bash
php artisan vendor:publish --tag=dujana-arabic-nlp
```
ستجد الرابط في:

```php
storage_path('app/dujana/lexicon')
```

الصيغة:

```tsv
form	root	pos_cat	pos	language
تنزف	نزف	verb	فعل	fusha
أحلام	حلم	noun	اسم	fusha
```

يفيد هذا الملف في:

- الجذور المعتلة.
- الجذور المهموزة.
- الكلمات الشائعة التي تريد تثبيت نتيجتها.
- الكلمات التي لا تكفي القواعد وحدها لتحليلها بأمان.


### أمان ملفات TSV اليدوية

تُستورد ملفات TSV اليدوية عبر باني القاموس باستخدام PDO prepared statements، ولا يُدمج محتوى TSV مباشرة داخل عبارات SQL.

ومع ذلك، ينبغي التعامل مع ملفات TSV بوصفها مدخلات بناء محلية. لا تستورد ملفات TSV مولّدة من مستخدمين غير موثوقين دون التحقق منها. تقص دُجانة الحقول، وتتجاهل الصفوف التي تخلو من الصيغة أو الجذر، وتضع حدودًا لطول الحقول قبل إدخالها في قاعدة SQLite الاختيارية.
