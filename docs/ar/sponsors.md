# الرعاية

دُجانة مشروع يهدف إلى توفير أدوات عملية لمعالجة العربية الفصحى في PHP وLaravel.

تساعد الرعاية في استمرار:

- تطوير القواعد الصرفية.
- تحسين مستوردات القواميس.
- بناء مجموعات تقييم أفضل.
- كتابة توثيق عربي وإنجليزي واضح.
- صيانة دعم Laravel.

إذا كنت تستخدم دُجانة في مشروع تجاري أو بحثي، ففكر في دعم تطويرها.
