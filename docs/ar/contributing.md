# المساهمة

نرحب بالمساهمات التي تحسّن دُجانة علميًا وعمليًا.

أمثلة مفيدة:

- إضافة قواعد صرفية قابلة للاختبار.
- تصحيح جذور يدوية.
- توسيع مجموعات التقييم.
- تحسين التوثيق العربي والإنجليزي.
- إضافة اختبارات Laravel.

إرشادات عامة:

- لا تكرر القواعد أو الدوال بين الأصناف.
- أضف اختبارًا لكل قاعدة صرفية جديدة.
- اجعل الجذر غير موثوق عندما تكون القاعدة ظنية.
- أبقِ وضع Root حذرًا.
- اجمع منطق اللواحق والبادئات في سياسات مشتركة قدر الإمكان.
