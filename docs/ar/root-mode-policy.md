# سياسة وضع الجذر

وضع Root في دُجانة صرفيّ واعٍ، لكنه حذر.

ترتيب الثقة العام:

1. الجذور اليدوية.
2. مدخلات قاعدة القاموس.
3. القواعد الصرفية ذات الثقة العالية.
4. fallback محافظ عند غياب الدليل.

لا تتعامل مع كل fallback بوصفه جذرًا يقينيًا. في الإنتاج، راجع المصدر والثقة وسبب الاعتمادية قبل تخزين النتيجة أو عرضها بوصفها حقيقة صرفية.
