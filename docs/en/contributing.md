# Contributing

Contributions are welcome.

Good contributions include:

- New morphology rules with tests.
- Manual root corrections.
- Better evaluation suites.
- Documentation improvements.
- Laravel integration tests.

Guidelines:

- Do not duplicate rule methods across classes.
- Add tests for every morphology rule.
- Mark ambiguous roots as non-authoritative when needed.
- Keep root mode cautious.
- Prefer shared policies for clitics and suffixes.
