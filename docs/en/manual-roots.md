# Manual roots

Manual roots are TSV rows used to improve production behavior.

```bash
php artisan vendor:publish --tag=dujana-arabic-nlp
```
ستجد الرابط في:

```php
storage_path('app/dujana/lexicon')

```

Format:

```tsv
form	root	pos_cat	pos	language
تنزف	نزف	verb	فعل	fusha
أحلام	حلم	noun	اسم	fusha
```

Use manual roots for:

- Weak roots.
- Hamzated roots.
- Common production corrections.
- Lexical forms that rules cannot safely infer.


### Manual TSV safety

Manual TSV files are imported through the lexicon builder using PDO prepared statements. TSV content is never interpolated directly into SQL.

Even so, TSV files should be treated as local build input. Do not import TSV files generated by untrusted users without validation. Dujana trims fields, ignores empty form/root rows, and limits field lengths before inserting them into the optional SQLite lexicon database.
