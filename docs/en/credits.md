# Credits

Dujana is independent software, has its own Philosophy. It can optionally import or interoperate with external lexical resources.

## Qabas

Qabas is an open-source Arabic lexicographic database designed for NLP applications. It is developed by SinaLab / Birzeit University and described in the LREC-COLING 2024 paper “Qabas: An Open-Source Arabic Lexicographic Database”.

Resources:

- https://sina.birzeit.edu/qabas
- https://aclanthology.org/2024.lrec-main.1170/
- https://arxiv.org/html/2406.06598v1

Check the Qabas website and license terms before redistributing imported data.

## Arramooz

Arramooz Alwaseet is an open Arabic dictionary for morphological analysis. Its public project pages describe stop words, verbs, and nouns, and provide downloadable dictionary files.

Resources:

- https://github.com/linuxscout/arramooz
- https://sourceforge.net/projects/arramooz/
- https://sourceforge.net/projects/arramooz/files/
- https://github.com/linuxscout/arramooz-pysqlite
- https://pypi.org/project/arramooz-pysqlite/

Check the project license before redistribution.
